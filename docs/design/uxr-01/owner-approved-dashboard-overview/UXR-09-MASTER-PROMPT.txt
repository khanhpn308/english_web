## 5. TOP-LEFT HERO CARD — “VIỆC CẦN LÀM HÔM NAY”

This is the most important dashboard block.

It must immediately answer:
What should the learner do right now?

Required content:
- title: “Việc cần làm hôm nay”
- primary message: “Ôn 12 thẻ đến hạn” (or equivalent synthetic example with the same structure)
- supporting sentence that explains urgency briefly
- 3 CTAs:
  1. primary: “Ôn 12 thẻ đến hạn”
  2. secondary: “Làm quiz ngắn”
  3. secondary: “Tra từ mới”

Visual priority rules:
- the primary CTA must be clearly dominant
- the block must be the first thing the eye sees together with the book carousel
- text must be concise
- no long paragraphs
- use iconography and strong hierarchy
- keep Direction B compactness while preserving readability

## 6. TOP-RIGHT BOOK CAROUSEL — “SÁCH HỌC GẦN ĐÂY”

This area replaces the previous static book progress block.

Books are strategically important for the product and must be highlighted.

This section must function conceptually as an auto-rotating horizontal carousel / auto-play slider.

### Required behavior concept
- show 5 most recently studied books
- display only ONE book at a time in the visible main banner
- no partial next/previous book should be visible in the same frame
- provide left and right navigation controls
- provide small pagination indicators/dots
- include auto-play behavior concept
- recommended auto-advance interval: around 4–5 seconds
- pause on hover or interaction should be documented conceptually
- agent does NOT need to build real production animation; only design the state and note intended behavior

### Required visual structure per visible book
- section title: “Sách học gần đây”
- small contextual label such as “5 sách học gần nhất”
- book cover
- book title
- learning status
- chapter progress
- lesson progress
- progress bar
- percentage complete
- primary CTA: “Tiếp tục học”
- secondary CTA: “Mở sách”

### Critical owner feedback that must be applied
- only one book is visible per carousel state
- do not show another book intruding into the same frame
- left/right buttons must be more subtle and slightly faded than before
- the carousel should feel like a focused learning-banner, not a cluttered slider
- this top book area is important and should feel like a product highlight

## 7. SECOND ROW KPI CARDS

Use 4 compact summary cards.

Required cards:
1. Thẻ đến hạn
2. Chuỗi học
3. Độ chính xác trắc nghiệm
4. Writing tự chấm

Required rules:
- each card must be scannable in under 1 second
- use icon + large number + concise subtext
- no repeated information from charts below
- avoid long descriptions
- use strong typography hierarchy
- Direction B should remain compact but not cramped

Recommended examples:
- Thẻ đến hạn: “12 / 58 thẻ” + “Cần ôn trong hôm nay”
- Chuỗi học: “7 ngày liên tiếp” + small positive delta
- Độ chính xác trắc nghiệm: percentage + answered count + delta
- Writing tự chấm: “3.6 / 4” + reviewed count + delta
